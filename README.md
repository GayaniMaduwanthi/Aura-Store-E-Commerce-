# 🛍️ Aura Store - Enterprise E-Commerce Platform

> A modern, responsive client-side e-commerce storefront featuring dynamic product management, wishlist persistence, sorting/filtering, user accounts, delivery checkout, and order history.

## 🌟 Key Features

* **🔎 Search, Category Filtering & Sorting:** Filter by *Electronics, Accessories, or Lifestyle*, search by keyword, and sort by price or name.
* **⚙️ Dynamic Product Management & Demo Reset:** Add new products, remove items, or reset back to default catalog data anytime.
* **❤️ Persistent Wishlist:** Save products for later and move them straight into the cart.
* **🛒 Interactive Cart & Delivery Checkout:** Adjust item quantities, enter recipient/phone/shipping address and payment method, and generate an instant order receipt.
* **👤 Account Auth & Order History:** Register/login locally and review past confirmed orders under **My Orders**.
* **🌙 Dark / Light Mode:** Theme switching persisted in browser storage with toast notifications.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Grid, Flexbox, CSS Variables), JavaScript (ES6+)
* **Persistence:** Browser `LocalStorage` API
